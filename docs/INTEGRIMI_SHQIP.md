# Plani i integrimit në V6.2

1. Ruaj kopje rezervë të të dhënave para çdo ndryshimi të APK-së.
2. Siguro projektin burimor Java/Kotlin të aplikacionit ose rindërto një host Android me WebView dhe ndërfaqen ekzistuese.
3. Integro \`GoogleSatelliteActivity\` të projektit demonstrues dhe shto butonin përkatës në ndërfaqen WebView.
4. Përditëso çelësin Google Maps me **package name dhe SHA-1 të APK-së finale** (do të ndryshojnë nëse nënshkruhet me certifikatë tjetër).
5. Testo menytë, sensorët, raportet dhe arkivat, dhe bëj testim të përditësimit pa humbje të dhënash.
6. Për analiza përdor burime satelitore të autorizuara; mos pretendo zbulim nëntokësor nga fotografia Google.

Status: Maps SDK demo është vetëm modul në zhvillim. Nuk ka APK të integruar dhe funksionale të konfirmuar në pajisje reale.
